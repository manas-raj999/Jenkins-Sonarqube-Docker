# Jenkins-SonarQube-Docker Project

This project showcases a basic DevOps pipeline using **Jenkins**, **SonarQube**, and **Docker** to automate code building, perform static analysis, and deploy containerized applications.

## 🔧 Tools & Technologies

* **Jenkins** – CI/CD automation  
* **SonarQube** – Static code analysis  
* **Docker** – Containerization platform  
* **Git/GitHub** – Version control  

## 🌐 Workflow Overview

1. Jenkins pulls the latest code from GitHub.  
2. Jenkins triggers a SonarQube scan for code quality analysis.  
3. If the quality gate passes, a Docker image is built.  
4. Docker runs the containerized application locally or in staging.  

## ✅ Features

* Continuous Integration pipeline  
* Code quality and security analysis  
* Docker-based containerization  
* Local or cloud deployment-ready
